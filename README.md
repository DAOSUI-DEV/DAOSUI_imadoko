# いまどこ（DAOSUI_imadoko）

親友グループで、**見せたい分だけ位置を見せ合う**アプリの試作。iPhoneのSafariで使う。
位置も名前も、全部スマホの中で暗号化してから送るので、中継サーバーにも、このサイトにも中身はわからない。

- 公開URL：`https://daosui-dev.github.io/DAOSUI_imadoko/`
- 今の段階：**試作 v0**（Web版）。画面をつけてページを開いている間だけ共有される
- 予定：使い心地を確かめたあと、iPhoneアプリ版（画面を消しても共有できる）を作る

## 1. 使う場面と前提

| 項目 | 決めたこと |
|---|---|
| 使う人 | 親友グループ（3〜10人）。基本的に友人だけで使う |
| 使う場面 | 普段からずっと |
| 作り方 | まずWebで試作 → あとでiPhoneアプリ（Expo＋EAS Build。Macなしで作れる） |
| Appleの年会費（約1.3万円） | 試作を見てから決める。iPhoneアプリを自分や友達の端末に入れるには必要 |
| サーバー代 | 無料で収める |
| 一番大事にすること | 個人情報の保護。守りは慎重に、厳重に |

## 2. 共有のルール

### 見せ方は3つ

| 状態 | 相手に見えるもの | 送る間隔 |
|---|---|---|
| **正確** | 今いる場所そのもの（約1mの細かさ） | 5分ごと（合流モード中は10秒ごと） |
| **あいまい** | 約1kmのマス目の真ん中。地図では大きい円で表示 | 同上 |
| **オフ** | 何も送らない。最後に送った位置が「◯分前」として残る | 送らない |

### 決めたルール
- **最初の状態はオン（正確）**。ただし最初の1回は、本人が見せ方を選んで「始める」を押すまで何も送らない。
- **自分がオフでも、相手が見せている分は見える。**
- **オフにしたことは相手に伝わらない。** 止まっている人や電波のない人と同じ見え方になる。あいまいは円が大きくなるのでわかる。
- **最後の位置は12時間残って、そのあと消える。** すぐ消したい時は、設定の「今の位置をすぐ消す」を使う（消してオフになる）。
- **合流モード**：10秒ごとに送る。30分たったら自動で普段のモードに戻る。オフの間は使えない。

### 「あいまい」のしくみ
世界共通の約1kmのマス目を決めておいて、今いるマス目の**真ん中の座標**を送る。
送るたびに少しずつずらす方式だと、何回分か平均すると本当の位置がわかってしまう。だからこの方式にした。

## 3. 機能

| 機能 | 内容 | 状況 |
|---|---|---|
| グループを作る | グループ名とあだ名を決めて作る | 済み（v0） |
| 招待リンク | LINEで送る。10分で使えなくなる | 済み（v0） |
| 見せ方の切り替え | 正確／あいまい／オフ。画面の上の帯でワンタップ | 済み（v0） |
| 共有中の表示 | 今の状態と「最後に送った時刻」がいつも画面の上に出る | 済み（v0） |
| 地図 | Googleマップのように指で動かして拡大・縮小できる地図（OpenFreeMap）。友達はアイコンで表示。「全員」「自分」ボタンで表示を合わせる | 済み（v0.1） |
| レーダー表示 | 地図を読みこめない時の予備。自分を中心に方角と距離を表示（上が北）。50mまで近づける・2本指で縮尺を変えられる | 済み（v0.1） |
| 合流モード | 10秒ごと・30分で自動で戻る | 済み（v0） |
| 新しく入った人の知らせ | 誰かが入ると、全員の画面に名前が出る | 済み（v0） |
| 通信ログ | 送った・受け取った・はじいたメッセージ、出入りの記録、「サーバーから見える形」 | 済み（v0） |
| 今の位置をすぐ消す | サーバーから消してオフにする | 済み（v0） |
| グループを抜ける | 自分の名前と位置をサーバーから消し、スマホの鍵も消す | 済み（v0） |
| メンバーを外す | 全員が外せる。誰が外したかは全員に表示。外したら鍵を作り直す | 次の版 |
| 集合ピン | 地図に「ここに集合」。24時間で消える | 次の版 |
| ひとことステータス | 20文字まで。12時間で消える | 次の版 |
| 近くに来たら通知 | 300m以内。あいまいの人は2km以内で、ぼかした位置で判定 | 次の版 |
| 自分の履歴 | 自分の端末の中だけに暗号化して保存。7日で消える | 次の版 |
| 住んでる地域の地図を丸ごと保存 | よく使う地域の地図をスマホに保存して、見てる場所を地図の会社にも伝えない | 次の版 |
| 電池残量 | 10%単位で表示 | iPhoneアプリ版（SafariのWebページでは電池残量を取れない） |
| Face IDで開く | 設定でオンにできる（最初はオフ） | iPhoneアプリ版 |

## 4. 非機能

| 項目 | 決めたこと |
|---|---|
| 対応する端末 | iPhoneのSafari（Web版）。あとでiPhoneアプリ版 |
| 1グループの人数 | 3〜10人を想定 |
| 更新の速さ | 普段5分ごと、合流モード中は10秒ごと |
| 届くまでの時間 | 送ってから数秒以内（中継サーバーしだい） |
| 電池 | 普段は5分ごとに抑える。Web版は画面をつけたままにする設定もある（電池は減りやすい） |
| 電波が悪い時 | 自動でつなぎ直す。切れている間は画面の上に表示が出る |
| 費用 | 0円（無料の公開中継サーバー、無料の地図 OpenFreeMap、GitHub Pages）。iPhoneアプリ版はCloudflareの無料枠を予定 |
| Web版の限界 | 画面を消したりSafariを閉じたりすると共有が止まる（iPhoneのSafariは、裏でWebページに位置を取らせない） |

## 5. セキュリティ設定

### 守る相手と対策

| 守る相手 | 心配なこと | 対策 |
|---|---|---|
| 中継サーバー・運営する人 | 位置を見られる・ためこまれる | 全部スマホの中で暗号化。サーバーには読めない文字の並びを、決めた時間だけ置く |
| 通信ののぞき見 | 途中で読まれる | 暗号化した通信（wss）の上で、さらに中身を暗号化 |
| グループの外の人 | 招待リンクが流出して入られる | 10分で期限切れ。入った人の名前は全員に表示。外す機能は次の版 |
| 外からの偽物 | 偽の位置や知らせを書き込まれる | 鍵がないと正しい形のメッセージを作れない。開けないものは捨てて、ログに出す |
| 盗んだメッセージの再送 | 古い位置を送り直される | 同じメッセージの2回目と、10分以上前のメッセージは捨てる |
| 抜けた人 | 抜けたあとも見られる | 次の版：外したら鍵を作り直す |
| スマホの紛失・盗難 | 拾った人に見られる | iPhoneのパスコードに任せる。次の版：ほかのメンバーがすぐ外せる |
| 地図の会社 | 見ている場所が伝わる | 地図は OpenFreeMap（無料・登録なし・クッキーなし。普段の記録にIPを入れず7日で消す方針）。友達の位置やグループのことは送らない。どのページから来たかも伝えない。次の版で、住んでる地域は丸ごと保存して何も伝えないようにする |
| 端末のつながり | 別の日のグループと同じ人だと結びつけられる | 中継サーバーへの接続IDは毎回ランダム。メンバーIDもグループごとに作る |

### 暗号の設定

| 項目 | 設定 |
|---|---|
| 暗号の方式 | AES-GCM（256bit）。改ざんされたものは開けない |
| グループの鍵 | 32バイトの乱数。グループを作った人のスマホで作る |
| 鍵から作るもの | HKDF（SHA-256）で「メッセージの鍵」と「サーバー上の置き場所の名前」を別々に作る |
| 置き場所の名前 | `q/` ＋ 鍵から作った32文字の英数字。グループ名・名前・座標はサーバーに出ない |
| 付けている印 | 置き場所の名前を暗号に結びつけている（別の置き場所に貼り替えると開けない） |
| 再送の防止 | 一度見たメッセージは捨てる。保存分以外で10分以上前のものも捨てる |

### サーバーに置くもの

| 置くもの | 中身 | 消えるまで |
|---|---|---|
| 今の位置 | 見せ方・座標・合流モードかどうか（暗号化） | 12時間（新しい位置で上書き） |
| 名簿 | あだ名・入った時刻（暗号化） | 30日（開くたびに更新）。抜けたらすぐ消す |
| 招待 | グループの鍵を、招待の鍵で包んだもの | 10分 |
| お知らせ | 入った・抜けた（暗号化） | 保存しない（その場で届けるだけ） |

- **置かないもの**：位置の履歴、本名、電話番号、メールアドレス、アカウント
- **消える時間のしくみ**：MQTT 5 の有効期限を使う。MQTT 5 が使えないサーバーの時は、抜ける時に自分で消す
- **サーバーに見えてしまうもの**：意味のない文字の並び、その大きさ、送った時刻、接続元のIPアドレス

### 招待のしくみ
1. 招待する人のスマホで「招待の秘密」（32バイトの乱数）を作る。
2. グループの鍵を、招待の秘密から作った鍵で包んで、サーバーに10分だけ置く。
3. リンクは `…/?openExternalBrowser=1#i1.<サーバー>.<招待の秘密>` の形。**「#」より後ろはブラウザがサーバーに送らない**ので、GitHubにも中継サーバーにも秘密は届かない。
4. リンクを開いた人のスマホで包みを開けて、グループの鍵を受け取る。開いたらすぐアドレスバーから秘密を消す。
5. 10分たつと、サーバーの包みが消える。リンクだけ残っても、もう何も開けない。

### スマホに保存するもの
- グループの名前・鍵・自分のメンバーID・見せ方（`imadoko.` で始まる名前で保存）
- 自分のあだ名（次に入る時の入力を楽にするため）
- 通信ログは**保存しない**（メモリの中だけ。ページを閉じると消える）
- 注意：GitHub Pages では、同じアカウントのサイト（`daosui-dev.github.io` の下）が同じ保存場所を共有する。中身は全部自分のサイトなので問題ないけど、iPhoneアプリ版では鍵をiPhoneのキーチェーンに入れる

### 通信先の制限
ページに Content-Security-Policy を設定して、つなげる先を次の4つだけに絞っている。それ以外の外部サービス（Googleなど）にはつながらない。
- `wss://broker.hivemq.com:8884`（HiveMQ・中継）
- `wss://broker.emqx.io:8084`（EMQX・中継）
- `wss://mqtt.eclipseprojects.io`（Eclipse財団・中継）
- `https://tiles.openfreemap.org`（OpenFreeMap・地図。表示してる範囲の地図・文字の形・アイコンだけを取る）

地図の部品（MapLibre GL JS）もこのサイトから読みこむ。外の配信サービス（CDN）は使わない。

あわせて `no-referrer` で、どのページから来たかも伝えない。

### 残るリスク
- 招待リンクが10分以内に流出すると、知らない人が入れる（承認なしを選んだため）。入った瞬間に全員の画面に名前が出る。
- 中継サーバーには、IPアドレスと通信した時刻・量は見える（中身は見えない）。
- 地図の会社（OpenFreeMap、配信にCloudflareを使うことがある）には、表示した範囲の地図を取ったことと接続元のIPアドレスが伝わる。友達の位置は伝わらない。
- アプリを改造して嘘の位置を送る人は防げない（友達だけで使う前提）。
- ロックのかかっていないiPhoneを拾われると、その間は見られる。

## 6. 仮で決めたこと（あとで変えてもいい）
- アカウントは作らない（電話番号・メールなし）。名前はあだ名
- 機種変更の時は招待し直してもらう（鍵のバックアップは作らない）
- 近くに来たら通知：最初は300m
- サーバーのアクセス記録は残さない（iPhoneアプリ版のCloudflareで設定する）

## 7. 開発と公開

### ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（画面・暗号・通信を1つのファイルに入れている） |
| `mqtt.min.js` | 中継サーバーと話すためのライブラリ（mqtt.js 5.15.1、MITライセンス） |
| `mqtt.LICENSE.txt` | mqtt.js のライセンス |
| `maplibre-gl.js` ほか3つ | 地図を表示する部品（MapLibre GL JS 6.11.2、BSD-3-Clause） |
| `maplibre.LICENSE.txt` | MapLibre GL JS のライセンス |
| `.nojekyll` | GitHub Pages がファイルをそのまま出すための印 |

### 中継サーバーの選び方
グループを作る時に、HiveMQ → EMQX → Eclipse の順につないで、最初につながったサーバーをそのグループで使う。どのサーバーかは招待リンクの1文字（`h`／`e`／`c`）でわかる。

### 公開の設定（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして Save。

### 地図
- 地図データ：OpenStreetMap（みんなで作っている世界地図）。OpenFreeMap が無料で配っているものを使う（スタイルは Liberty）
- 地名は日本語の名前があれば日本語で出す。漢字やかなはiPhoneの文字で描く（文字の形のデータを取りに行く量を減らすため）
- 地図の右下に、出どころ（OpenFreeMap・OpenMapTiles・OpenStreetMap）を表示する（使う条件）
- 地図を12秒たっても読みこめない時は、レーダー表示に切り替える

### テストのしかた
自分のパソコンの中（`localhost`）で開いた時だけ、URLに次を付けられる。公開版ではどれも無視される。
- `?broker=ws://localhost:8889`：自分のパソコンの中の中継サーバーにつなぐ
- `&invttl=4`：招待の期限を4秒にする（期限切れのテスト用）
- `&mapstyle=local`：外につながない、テスト用の地図にする
